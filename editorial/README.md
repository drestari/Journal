# AJSMR Editorial Management System V1
PHP/MySQL starter application with Admin, Editor-in-Chief, Editor, Reviewer, Author and Production roles.

Workflow:
SUBMITTED -> TECHNICAL_CHECK -> PLAGIARISM_CHECK -> EDITORIAL_SCREENING -> ASSIGNED_TO_EDITOR -> REVIEWER_INVITATION -> UNDER_REVIEW -> REVISION_REQUIRED -> REVISED_SUBMISSION -> SECOND_REVIEW -> ACCEPTED -> PRODUCTION -> PROOF_SENT -> PROOF_APPROVED -> PUBLISHED

Installation:
1. Import database.sql into MySQL.
2. Edit config/config.php with the production database credentials and BASE_URL.
3. Upload the folder as /editorial/ under AJSMR.
4. Ensure uploads/manuscripts, revisions, reviews and proofs are writable.
5. Create the first administrator using a password hash generated by password_hash(), then create all other users from Admin > Users.
6. Enable HTTPS and use a dedicated MySQL account.
7. For production deployment, add secure private-file delivery, email notifications, revision upload, reviewer invitation assignment, plagiarism-report attachment, proof upload, DOI registration, rate limiting, malware scanning and automated backups.

This V1 provides the database foundation, authentication, role dashboards, author submission, editorial status control, reviewer review forms, production status, issues, reports and audit logging.
